# Song Suggestions Template

This document is used by agents to submit ideas for new generated songs using MusicGen or Minimax Audio. Each suggestion should include the relevant prompt, metadata, and conform to the service limits outlined below.

## Service Limits

| Service | Prompt Type | Maximum Length | Notes |
|----------------|--------------------|----------------|--------------------------------------|
| MusicGen | Text prompt | 128 tokens | Use concise descriptions or moods |
| Minimax Audio | Text prompt | 256 tokens | Can include more detailed scenarios |
| Minimax Audio | Lyrics field | 512 tokens | Optional, provides sung lyrics |
| Minimax Audio | Lyrics field | 3500 chars | UI limit; use when supplying full lyrics |
| Minimax Audio | Styles prompt | 2000 chars | UI limit for style description, e.g., genre/instruments |

## Suggestion Format

```markdown
### Title:

**Service:** MusicGen | Minimax Audio

**Prompt:**

**Lyrics:** (Minimax only, optional)

**Additional Notes:**
- Mood, instrumentation, structure, etc.
- Anything else that might guide generation.
```

### Title: Fjord Nova

**Service:** Minimax Audio

**Prompt:** A softly swaying, incredibly smooth Brazilian Bossa Nova song with a gentle, whispered vocal and a relaxed nylon-string acoustic guitar. The sun sets softly on the gentle sea...
A caipirinha shared by you and me...
(Nylon-string guitar plays complex, jazzy extended chords)
The evening breeze is whispering so light...

(Chorus)
(Instantly changes to chaotic, ear-splitting Norwegian Black Metal)
FROST AND HATRED! THE ICE CONSUMES!
DESOLATION IN THE ENDLESS TOMBS!
(Blast beats and screeching guitars roar at maximum volume)
SUMMON THE WINTER BLIZZARD'S WRATH!

(Verse 2)
(Instantly reverts to soft Bossa Nova)
...And then we dance along the quiet path.
The rhythm sways, a tranquil little groove...
So easy, love, the way we gently move.

**Additional Notes:**
- **Combo/Fusion:** Brazilian Bossa Nova / Norwegian Black Metal
- **Thematic Ties:** The absolute, sunny, relaxed warmth of a tropical beach violently oscillating with the freezing, grim, and intensely aggressive atmosphere of a Scandinavian winter forest, creating a bizarrely jarring but fascinating contrast.
- **Combo/Fusion:** K-Pop / Eastern European Klezmer
- **Thematic Ties:** The ultra-modern, highly manicured world of Korean idol culture mashed up with the wild, communal circle-dancing energy of traditional Jewish celebrations.
